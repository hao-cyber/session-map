关于与帮助

三秒找回当时的自己

SessionMap 按工作主线整理本机 coding agent session，保留决定、失败尝试和继续工作的准确入口。

先从哪里看

  1. 1
    待处理

    先看等你拍板、回复、审阅或仍然卡住的工作。

  2. 2
    工作线

    主题是一级对象；Session 是主题里的执行入口。

  3. 3
    回到终端

    终端还在就聚焦；已经关闭就恢复原 session。

常用操作

点击主题
展开或收起 Sessions 目录
查看脉络
展开主题唯一的因果路径
双击 Session
执行“回到终端 / 恢复终端”
右键主题
归档；可立即撤销

数据留在你的控制范围内

地图和状态只保存在本机；transcript 始终只读；没有 SessionMap 账户、使用情况统计或遥测。整理时，只有有界增量会交给你选择并已登录的 Roll 引擎。

命令行入口

sessionmap open打开地图
sessionmap now查看现在需要处理什么
sessionmap --help查看全部命令
