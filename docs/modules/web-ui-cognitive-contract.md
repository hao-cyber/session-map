# Web UI 认知交互契约

> 本文是 [`web-ui.md`](web-ui.md) 的认知设计 spoke。产品含义、对象所有权与颜色语义仍由
> [`../product-design.md`](../product-design.md) 裁决；本文只把“三秒恢复”转成读取层可验证规则。

## 目标与边界

读取层不是让用户记住更多信息，而是提供足够好的提取线索，让用户在切回工作时依次回答：

1. 什么需要我；
2. 这是哪条工作线；
3. 为什么走到这里；
4. 从哪里继续。

心理学研究用于提出设计假设，不替代真实任务验证。工作记忆容量、反馈延迟和注意窗口都
随任务与用户而变；`3–4 chunk`、`400ms` 或 `800ms` 只能作为工程起点，不能写成普适定律。

## 认知不变量

### 注意力：状态负责显著，顺序负责稳定

- “待处理”只包含需要用户行动的 decision、reply、review 与 blocker。
- busy、recent 和更新时间不得凭事件数量压过明确 ask。
- 状态变化不重排已有 Session；状态色、文字和原位反馈承担变化提示。
- 同一视区不得再新增与“待处理”竞争的 Now 条、继续卡或活动 feed。

依据：Guided Search、变化盲视与 inhibition of return。稳定位置形成搜索先验；频繁重排会
让用户重新建立视觉搜索模板。

### 分块：一个感知对象只回答一个问题

- 左栏待处理项回答“什么需要我”。
- 主题标题回答“是哪条工作线”，主题脉络回答“为什么”。
- 主题脉络控件紧邻主题标题以表达所有权，但保持独立交互边界；窄屏换行时脉络控件对齐
  标题文字左缘，主题状态靠行末，不能夹在标题与脉络控件之间制造错误分组。
- Session 行回答“当前进展与从哪里继续”。
- 连接线只编码脉络节点的因果关系；主题与 Session 的目录归属使用公共区域、缩进和分组标题，
  不复用树线，避免把不同对象类型合并成一个错误的感知分组。
- 标题、最新进展、状态和恢复动作必须处于同一 Session 行，不能分散到工具栏或浮层。

依据：Object-Based Attention、Gestalt 邻近与 split-attention effect。

### 提取：识别优于回忆

- Session 主标题描述整段工作对象；最新进展必须描述结果、卡点或下一步，禁止“调试进展”
  等无提取价值文案。
- cwd、worktree、branch 和时间只作为恢复情境，不能取代语义标题。
- 完整因果脉络默认渐进披露，但当前路径、结构转折和 session cursor 必须可直接识别。
- 脉络节点类型必须用短文字直接识别；图形标记只能辅助，不能要求用户先记住一套形状图例。
- 节点的原因或证据与标题保持同一对象内的第二行，避免在一条拥挤扫描线上混合结论、解释
  和 session 落点。

依据：recognition over recall、encoding specificity 与情境线索提取。

### 反馈：结果留在动作对象上

- 跳转、恢复、暂停、归档和删除在触发后立即在原控件显示 busy/disabled 状态。
- toast 只能补充最终结果，不能承担唯一反馈。
- 同一 Session 动作在途时去重，避免重复恢复造成不可预测结果。

依据：Norman 的 Mapping、Constraint 与 Feedback。

### 错误预防：显著性与风险匹配

- 高频、可逆的恢复动作必须可见且有明确文字。
- 删除保持低显著，但必须可通过键盘发现，并在执行前解释 SessionMap 记录、原 transcript
  与共享主题脉络的实际影响。
- 颜色永远不是唯一状态线索；状态词、图标或结构至少提供一个冗余通道。

## 任务式验证

每次改变信息层级、字体、状态呈现、目录密度或恢复入口时，至少用以下虚构状态截图和交互：

1. decision 与 reply 同时存在；
2. blocker 没有可恢复 Session；
3. busy 但无需用户介入；
4. 已关闭 Session 可恢复；
5. 多主题、多 Session、长标题与长进展。

在 1440×1000、1280×800 和窄屏下记录：

- 首个正确行动的发现时间与误点；
- 能否说出工作线和最近有意义进展；
- 能否找到恢复入口；
- 展开、刷新和 resize 后能否重新定位原主题或 Session；
- 键盘焦点、减少动态效果、文字溢出和状态非颜色线索是否完整。

“三秒”是产品目标，不用单次设计者自测宣称达成。截图证明层级与溢出，自动测试证明契约
未被删除，真实任务测试才证明用户能够恢复思考位置。
